大家应该都听说过热水器传奇，呆在宿舍里面的人应该也体验过这种感受，可能我也体验过吧那种左调1度冰霜世界，右调1度十级烫伤的感觉，是不是让你有所耳闻？于是我就写了这个程序，专门来解决这个问题。
我们并不采用人工智能，而是采用某些感受来做，就比如说你太烫的时候，你就按一下那个按钮。好吧，实际上我并没有这些配件送给大家，大家自己上网去买吧。
这是以下的配件
一个单片机(Arduino那种的）
一个温度控制器
一个加热器
一个屏幕
一个继电器
一些杜邦线
相信大家都会编译了吧，我告诉大家这些库
1. Adafruit SSD1306
2. Adafruit GFX
3. OneWire
4. DallasTemperature
5. PN532
大家自己去一个一个装好，然后接下来就是接线教程，按照这样子接，绝对没有问题。
温度传感器:
  VCC → 5V
  GND → GND
  DATA → 引脚2

OLED:
  VCC → 3.3V
  GND → GND
  SCL → A5
  SDA → A4

NFC读卡器:
  VCC → 3.3V
  GND → GND
  SDA → A4
  SCL → A5

按钮:
  太热按钮 → 引脚4
  太冷按钮 → 引脚5
  合适按钮 → 引脚6

加热器继电器:
  IN → 引脚3
  VCC → 5V
  GND → GND
